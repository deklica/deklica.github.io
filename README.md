# dEXE's Kodi Add-ons Hub

[![Donate](https://img.shields.io/badge/Donate-Ko--fi-FF5E5B?logo=kofi&logoColor=white)](https://deklica.github.io/#donate)

Source of **[deklica.github.io](https://deklica.github.io)**, the website for dEXE's Kodi add-ons: releases, add-on catalog, references and step-by-step tutorials.

This repo is also a Kodi file source: the repository zips are served from its root.

## Install in Kodi

1. **Settings ? File manager ? Add source** and enter:
   ```
   https://deklica.github.io
   ```
2. **Settings ? Add-ons ? Install from zip file**, open the source and install `repository.dexe-….zip` (and optionally `repository.roooar-….zip`).
3. **Install from repository** and pick the add-ons you want. Updates arrive automatically.

Screenshots for every step are in the [Tutorials](https://deklica.github.io/#tutorials).
