Omogućite instalaciju iz ZIP fajla u Kodi-ju

Otvorite Settings › System › Add-ons i omogućite opciju Unknown sources.

Metod 1

Instalacija putem preuzetog Repository ZIP fajla

  1. Preuzmite ZIP fajl repozitorijuma (repository.dexe-x.y.z.zip ili repository.roooar-x.y.z.zip) iz taba Preuzimanje.
  2. U Kodi-ju idite na Add-ons › Install from ZIP file.
  3. Pronađite i izaberite preuzeti ZIP fajl.
  4. Sačekajte obaveštenje Add-on installed.
  5. Idite na Install from repository i izaberite instalirani repozitorijum (npr. dEXE's Addons Repository).
  6. Pregledajte kategorije (npr. Subtitles, Services ili Skins) i izaberite addon koji želite da instalirate.
  7. Kliknite na Install i potvrdite instalaciju potrebnih zavisnosti (dependencies).
Metod 2

Instalacija putem Kodi File Manager-a (direktni GitHub izvor)

  1. Otvorite Settings › File Manager.
  2. Kliknite na Add source.
  3. Za putanju (path) unesite tačno: https://deklica.github.io i kliknite OK.
  4. Unesite ime za izvor (source), npr. dEXE's Addons, i kliknite OK.
  5. Vratite se na Add-ons › Install from ZIP file.
  6. Izaberite izvor koji ste dodali (dEXE's Addons).
  7. Izaberite ZIP fajl repozitorijuma (repository.dexe-x.y.z.zip ili repository.roooar-x.y.z.zip).
  8. Sačekajte obaveštenje Add-on installed.
  9. Idite na Install from repository i izaberite instalirani repozitorijum (npr. dEXE's Addons Repository).
  10. Pregledajte kategorije (npr. Subtitles, Services ili Skins) i izaberite addon koji želite da instalirate.
  11. Kliknite na Install i potvrdite instalaciju potrebnih zavisnosti (dependencies).

Addoni se instaliraju isključivo kroz repozitorijum, pa se automatski ažuriraju (Auto-updates).

Enable ZIP installation in Kodi

Open Settings › System › Add-ons and enable Unknown sources.

Method 1

Install via Repository ZIP file

  1. Download the repository ZIP file (repository.dexe-x.y.z.zip or repository.roooar-x.y.z.zip) from the Releases tab.
  2. In Kodi, go to Add-ons › Install from ZIP file.
  3. Navigate to and select the downloaded ZIP file.
  4. Wait for the Add-on installed notification.
  5. Go to Install from repository and select the installed repository (e.g., dEXE's Addons Repository).
  6. Browse the categories (e.g., Subtitles, Services or Skins) and select the add-on you want to install.
  7. Click Install and confirm any dependencies.
Method 2

Install via Kodi File Manager (direct GitHub source)

  1. Open Settings › File Manager.
  2. Click Add source.
  3. For the path, enter exactly: https://deklica.github.io and click OK.
  4. Enter a name for the source, e.g., dEXE's Addons, and click OK.
  5. Go back to Add-ons › Install from ZIP file.
  6. Select the source you added (dEXE's Addons).
  7. Select the repository ZIP file (repository.dexe-x.y.z.zip or repository.roooar-x.y.z.zip).
  8. Wait for the Add-on installed notification.
  9. Go to Install from repository and select the installed repository (e.g., dEXE's Addons Repository).
  10. Browse the categories (e.g., Subtitles, Services or Skins) and select the add-on you want to install.
  11. Click Install and confirm any dependencies.

Add-ons are installed only through the repository, so they update automatically (Auto-updates).
